# PROJECT YADRO: THE CHERNOBYL TAPES
### Declassified KGB Digital Archive & Transmedia Experience (BCM 216 - Autumn 2026)

**Project Yadro** is an alternate-history, Cold War sci-fi and psychological horror transmedia franchise created for BCM 216. Rather than a single linear story, the project distributes its narrative across four distinct media pillars:
1. **Primary Artefact (Audio Podcast):** *The Chernobyl Tapes* (Episode 1: *The Man Beneath Reactor 4*, Episode 2: *Who Destroyed the Soviet Union?*).
2. **Narrative Extension (Short Story):** *The Man in the Lead Apron* (Dr. Anatoly Yadro's pre-1986 biography & abduction).
3. **Digital Investigation (Classified KGB Archive):** Interactive leaked memos, contradictory eyewitness logs, and forensic audience engagement.
4. **Diegetic Physical Artefacts:** High-res Soviet nuclear propaganda poster, printable DIY ДП-5Б (DP-5B) dosimeter cardstock blueprint, and an interactive Project Yadro Soviet Research ID badge generator.

---

## 🚀 Live Showcase & Usage

This repository is built with **zero external build dependencies** (pure semantic HTML5, modern CSS3, and vanilla JavaScript with the Web Audio API and HTML5 Canvas API).

### How to Run Locally:
1. Clone the repository:
   ```bash
   git clone https://github.com/sgh812/Project-Yadro.git
   ```
2. Double-click or open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).

### Deployment:
Ready for instant 1-click deployment on **GitHub Pages**, **Netlify**, or **Vercel**.
To enable on GitHub Pages:
- Go to repository **Settings** > **Pages**
- Under **Branch**, select `main` and `/ (root)`
- Click **Save**
